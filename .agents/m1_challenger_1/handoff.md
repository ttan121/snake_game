isInViewport(worldX, worldY, radius = 0) {

Fluctuating $\Delta t$ tests produced zero drift from the analytical curve.
4. **Premise 4 (Canvas Transform Consistency):** Canvas 2D operations nested between `applyTransform(ctx)` and `restoreTransform(ctx)` project world-space geometry to screen-space coordinates identically to `worldToScreen(x, y)`.
